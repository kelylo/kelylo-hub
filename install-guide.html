📱 How to Install KELYLO PWA

Your Ambition Hub - Available on All Devices

🤖

Android (Chrome / Samsung Internet)

1

Open the Website

Navigate to your KELYLO website in Chrome or Samsung Internet browser.

2

Wait for Install Prompt

After 3 seconds, a banner will appear at the bottom asking if you want to install the app.

3

Tap "Install"

Click the "Install" button in the banner, or tap the menu (⋮) → "Add to Home Screen".

4

Launch from Home Screen

The KELYLO icon will appear on your home screen. Tap it to launch the app!

🍎

iPhone / iPad (Safari)

1

Open in Safari

Navigate to your KELYLO website using Safari browser (not Chrome or other browsers).

2

Tap Share Button

Tap the Share icon at the bottom of the screen (square with arrow pointing up).

3

Add to Home Screen

Scroll down and tap "Add to Home Screen". Edit the name if desired, then tap "Add".

4

Open the App

Find the KELYLO icon on your home screen and tap to launch in full-screen mode!

💡 iOS Tip

Make sure you're using iOS 16.4 or later for the best PWA experience. Earlier versions work too, but may have limited features.

💻

Desktop (Chrome / Edge)

1

Open the Website

Visit your KELYLO website in Google Chrome or Microsoft Edge browser.

2

Look for Install Icon

You'll see an install icon (⊕ or computer icon) in the address bar on the right side.

3

Click Install

Click the install icon and confirm by clicking "Install" in the popup dialog.

4

Launch Desktop App

KELYLO will open in its own window and appear in your start menu/applications!

❓ Troubleshooting

💡 Install Prompt Not Appearing?

• Make sure you're on HTTPS (or localhost for testing)
• Clear your browser cache and reload
• Check if you already dismissed it (localStorage: pwa-install-dismissed)
• Try incognito/private mode
• Ensure service worker is registered (check pwa-test.html)
