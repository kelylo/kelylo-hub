# KELYLO - The Ambition Hub

Master 8 essential skills in 7 months. 20 hours per week. Transform your life.

## Features
- Progressive Web App (PWA) with install prompt
- Offline support via service worker
- Modern, responsive UI
- Skill pages for Word, PowerPoint, Canva, Excel, AutoCAD, SAP2000, Robot, and English
- AI-powered suggestions and file analysis

## Usage
1. Clone the repository:
   ```sh
   git clone https://github.com/kelylo/kelylo-hub.git
   ```
2. Serve locally (required for PWA features):
   ```sh
   cd kelylo-hub
   python -m http.server 8080
   ```
   Then open [http://localhost:8080](http://localhost:8080) in your browser.

## Deployment
- Deploy the contents of this folder to any static host (Cloudflare Pages, GitHub Pages, Netlify, Vercel, etc.)
- For GitHub Pages:
  1. Push to the `main` branch.
  2. In repository settings, set GitHub Pages source to `main` branch (root).
